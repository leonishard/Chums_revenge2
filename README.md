# Chum's Revenge 2

> A 2D Topdown Roguelike built for university coursework

## Tools:

- **Unity** - Game Engine
- **C#** - Programming Language

### Prerequisites

- Unity Editor (version compatible with this project)
- Git

### Installation

1. Clone the repository
```bash
git clone https://github.com/leonishard/Chums_revenge2.git
```

2. Open the project in Unity
   - Launch Unity Hub
   - Click "Add" and select the cloned project folder
   - Open the project in the appropriate Unity version

3. The project should automatically import and build the necessary Library files
